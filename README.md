# HTML_Exercise · HTML/CSS 入门练习

**在线浏览 / Live demo：<https://yanggu11.github.io/HTML_Exercise/>**

学习前端基础时的 HTML/CSS 练习合集，包括常见页面布局和仿写案例。

Practice pages from learning HTML and CSS: common layout techniques plus a few clone exercises.

## 练习列表 / Pages

| 页面 / Page | 内容 / Topic |
|---|---|
| [index.html](index.html) | 仿小米商城首页顶栏与导航 · Mi.com-style header and navigation |
| [案例一：小米顶部](templates/案例一：小米顶部.html) | 顶部导航栏布局 · Top navigation bar |
| [案例二：二级菜单](templates/案例二：二级菜单.html) | 悬停展开的二级菜单 · Hover drop-down sub-menu |
| [Example_4](templates/Example_4.html) | 商品推荐区块 · Product recommendation section |
| [浮动](templates/浮动.html) | `float` 布局与清除浮动 · Floats and clearing |
| [内边距](templates/内边距.html) | `padding` / `margin` 盒模型 · The box model |
| [高度和宽度](templates/高度和宽度.html) | 宽高设置与块级/行内元素 · Width, height, block vs inline |
| [login](templates/login.html) / [register](templates/register.html) | 登录、注册表单页 · Login and sign-up forms |

## 技术 / Tech

HTML5 · CSS3（Float 布局、盒模型、伪类 `:hover`）

## 本地运行 / Run locally

直接用浏览器打开 `index.html`，或打开 `templates/` 下的任意页面。

Open `index.html`, or any page under `templates/`, directly in a browser.
